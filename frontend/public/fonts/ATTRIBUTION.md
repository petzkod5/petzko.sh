# Fonts

Both faces are self-hosted (converted to `woff2`) so the site makes no
runtime request to an external font CDN.

## Px437 IBM VGA 8x16 — `Px437_IBM_VGA_8x16.woff2`

Used on the BIOS power-on / POST boot screen.

- Part of **The Ultimate Oldschool PC Font Pack (v2.2)** by VileR.

## VT323 — `VT323-Regular.woff2`

Used for the live terminal UI.

- By Peter Hull (The VT323 Project Authors), modelled on the DEC VT320 terminal.
- Source: https://fonts.google.com/specimen/VT323
